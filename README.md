# 3DGameStudy_Repository
 3D 게임 유니티 실습 수업
</br></br>

### 1일차
- 캐릭터 에셋 다운로드, 플레이어 움직임 구현, 카메라 시점 (1인칭, 3인칭, 플레이어는 움직이지 않는 3인칭) 구현
- c# 기초적인 구조 학습 (함수, 클래스, 변수선언)
- 레벨디자인1

### 2일차
- 총기 모델 에셋, 사운드, 애니메이션 추가
- 카메라 줌 상태 구현, 블랜트 트리 이용해서 3D상황의 애니메이션 구현, 사운드 약간 구현 (총 발사, 총기 장착)

### 3일차
- 애니메이터 레이어를 이용해서 상체, 하체 애니메이션 구별(Avatar Mask 이용)
- 캐릭터 컨트롤러와 다른 오브젝트 콜라이더가 충돌(트리거)하면 애니메이션, 사운드, 위치 이동 구현
  - 캐릭터 컨트롤러는 물리계산과 충돌 감지 계산을 위해서 자체적으로 위치를 강제 하기 때문에 트랜스폼으로 이동시킬려면 캐릭터 컨트롤러를 비활성화하고 이동시켜야 함.
- 피격 애니메이션, 픽업 애니메이션 구현
- 애니메이션 속도 조절 구현 : (AnimatorStateInfo)를 이용해서 애니메이터 레이어위치(베이스 레이어이거나 1이거나)를 확인하거나 애니메이션의 활성화 상태를 확인 가능함.
- rig 이용, 레이캐스트로 사격 구현
- 레벨디자인2

### 4일차
- LayCast로 LayerMask를 이용해서 충돌 체크
- LayCast 배열로 다수 충돌(관통) 구현, BoxLayCast로 아이템 픽업 상호작용 구현
- 픽업 오디오 추가
- 아이템(라이플)을 먹으면 1번 키가 활설화, 1번 실행 후 에임(조준, 우클릭)가능하게 수정
- 총구 화염 파티클 추가
- 플레이어 1차적으로 마무리
- 좀비 AI 기초 세팅(플레이어 추적, 회전)

### 5일차
- 좀비 애니메이션 추가 (걷고 있을때, 가만히 있을때, 데미지를 입었을때, 죽을때, 공격할때)
- 좀비 상태의 대한 함수 구현, 박스레이캐스트 디버그 출력 구현
- 좀비 사운드 추가
- 코루틴으로 ai 기반 구현 (기본 상태, 추적 상태, 순찰 상태, 공격 상태, 죽음 상태, [도망 상태], {일반 함수: 데미지 받은 상태})
   - ai를 구현할때 함수간의 충돌이나, 로직의 꼬임, 무한 선언 등의 문제를 해결하는 방법 중 하나는 코루틴을 이용해서 start코루틴과 stop코루틴을 이용한다
- 좀비 애니메이션 추가, ai 기본 구조 구현
- ai 자연스럽게 수정1, 하늘 스카이박스, 라이트,활용하여 어둡게 만듦
