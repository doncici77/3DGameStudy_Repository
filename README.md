# 3DGameStudy_Repository
 3D 게임 유니티 실습 수업
</br></br>

### 1일차
- 캐릭터 에셋 다운로드, 플레이어 움직임 구현, 카메라 시점 (1인칭, 3인칭, 플레이어는 움직이지 않는 3인칭) 구현
- c# 기초적인 구조 학습 (함수, 클래스, 변수선언)
- 레벨디자인1

### 2일차
- 총기 모델 에셋, 사운드, 애니메이션 추가
- 카메라 줌 상태 구현, 블랜트 트리 이용해서 3D상황의 애니메이션 구현, 사운드 약간 구현 (총 발사, 총기 장착)

### 3일차
- 애니메이터 레이어를 이용해서 상체, 하체 애니메이션 구별(Avatar Mask 이용)
- 캐릭터 컨트롤러와 다른 오브젝트 콜라이더가 충돌(트리거)하면 애니메이션, 사운드, 위치 이동 구현
  - 캐릭터 컨트롤러는 물리계산과 충돌 감지 계산을 위해서 자체적으로 위치를 강제 하기 때문에 트랜스폼으로 이동시킬려면 캐릭터 컨트롤러를 비활성화하고 이동시켜야 함.
- 피격 애니메이션, 픽업 애니메이션 구현
- 애니메이션 속도 조절 구현 : (AnimatorStateInfo)를 이용해서 애니메이터 레이어위치(베이스 레이어이거나 1이거나)를 확인하거나 애니메이션의 활성화 상태를 확인 가능함.
- rig 이용, 레이캐스트로 사격 구현
- 레벨디자인2
